# Terra Incognita Bugs
## About
This is a Repository to collect bugs sent by the community

If you found a bug by any means and you want to report it, [create an issue](https://github.com/SackBart/Terra-Incognita-Bugs/issues/new) <br>
Markdown is used to write issues. If you're not familiar with markdown, it's similar to discord's formating. <br>
Here's Markdown's [Syntax](https://www.markdownguide.org/basic-syntax/) for cool formating 😎
