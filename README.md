# Terra Incognita Bugs
## About
This is a Repository to collect bugs sent by the community

If you found a bug by any means and you want to report it, [create an issue](https://github.com/SackBart/Terra-Incognita-Bugs/issues/new) with the following format: <br>

**Topic** <br>
Give a brief description of the found bug

**Things I tried** <br>
I tried doing this and that but wow still no

**How to reproduce** <br>
- Open command line
- type "makebug"
- wait for 3 seconds
